My hands-on work is mainly focused on RP2040, C, bare-metal development, ARM Cortex-M0+, SWD and firmware analysis. I enjoy understanding systems from the hardware/software boundary down to registers, memory and communication protocols.

## 🚀 Featured Projects

**[Dolos — SWD Forensic Extractor](https://github.com/StheffannyNAlves/swd-forensic-extractor)**
An embedded firmware acquisition project built around two RP2040 boards — a bare-metal SWD probe currently validating the physical layer and target handshake (IDCODE), working toward full firmware acquisition from a target device.
`C` · `RP2040` · `ARM Cortex-M0+` · `SWD` · `USB` · `CMake` · `Python`

**[RP2040 Bare-Metal Research](https://github.com/StheffannyNAlves/Uart-baremetal-rp2040)**
A low-level exploration of the RP2040 boot process, runtime initialization, memory layout and peripheral access without relying on the Pico SDK.
`C` · `ARM Assembly` · `RP2040` · `MMIO` · `UART` · `Linker Script`
