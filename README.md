I'm an undergraduate student in Computer Engineering at UEFS, interested in low-level software, embedded systems and firmware security.

My hands-on work is mainly focused on RP2040, C, bare-metal development, ARM Cortex-M0+, SWD and firmware analysis. I enjoy understanding systems from the hardware/software boundary down to registers, memory and communication protocols.

I'm building toward high-performance backend systems that orchestrate hardware fleets (IoT, Edge) — which is why I split my current work between Java/Spring Boot backend development and embedded/hardware security research.

I'm also a member of the IEEE Robotics and Automation Society (RAS) and Women in Engineering (WIE) chapters at UEFS.

## 🚀 Featured Projects

**[Dolos — SWD Forensic Extractor](https://github.com/StheffannyNAlves/swd-forensic-extractor)**
An embedded firmware acquisition project built around two RP2040 boards — a bare-metal SWD probe currently validating the physical layer and target handshake (IDCODE), working toward full firmware acquisition from a target device.
`C` · `RP2040` · `ARM Cortex-M0+` · `SWD` · `USB` · `CMake` · `Python`
*Documented architecture (spec Rev. 5) — see project status for current implementation phase.*

**[RP2040 Bare-Metal Research](https://github.com/StheffannyNAlves/Uart-baremetal-rp2040)**
A low-level exploration of the RP2040 boot process, runtime initialization, memory layout and peripheral access without relying on the Pico SDK.
`C` · `ARM Assembly` · `RP2040` · `MMIO` · `UART` · `Linker Script`

**[Data Structures & Graph Algorithms](https://github.com/StheffannyNAlves/estrutura-de-dados)**
Core data structures implemented in C (linked list, stack, queue, AVL tree, B-tree, hash tables with chaining and linear probing) and graph algorithms in C++ (DFS, topological sort via Kahn's algorithm, Kruskal's MST with Union-Find, Prim's MST).
`C` · `C++`
